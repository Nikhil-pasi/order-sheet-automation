# Order Sheet Automation

Browser-based order processing tool for importing order data, correcting SKUs, and exporting the final sheet.

The final Excel workbook includes the Amazon Order ID between Product Name and Amazon FBA. It also includes a separate `Removed Orders` sheet containing excluded rows and their removal reasons.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server.

The application includes the corrected SKU mapping for the Nesta product: `NESTA0002`.
